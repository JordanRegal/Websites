# Project Instructions

## Project Goal

Build a simple, polished portfolio website for a freelancer. The website should present the freelancer clearly, showcase selected work, explain available services, and make it easy for potential clients to get in touch.

## Design Direction

- Keep the design modern, professional, welcoming, and uncluttered.
- Use **Poppins** as the primary font throughout the website.
- Use a **cream-beige background** with **bluish and navy-blue accents**.
- Use navy blue for strong headings, navigation, and primary actions; use the lighter blue for secondary accents and interactive details.
- Prioritize clear visual hierarchy, generous spacing, readable text, and consistent styling.
- Use a responsive, mobile-first layout that works well on phones, tablets, and desktops.
- Use subtle transitions and animation only when they improve the experience.
- Avoid unnecessary visual effects, excessive dependencies, and overcomplicated layouts.

## Suggested Page Structure

Unless the project brief changes, build a simple one-page portfolio with these sections:

1. Header and navigation
2. Hero introduction with a clear call to action
3. About
4. Services
5. Selected projects or portfolio
6. Contact call to action or contact form
7. Footer with relevant links

## Development Standards

- Prefer semantic HTML and accessible controls.
- Maintain sufficient color contrast and visible keyboard focus states.
- Give images useful alternative text and form fields clear labels.
- Keep components and styles easy to understand and maintain.
- Optimize images and avoid loading code that the site does not need.
- Do not add a framework or large dependency unless it provides a clear benefit.
- Use realistic placeholder content when final copy or assets are unavailable, and label it clearly for later replacement.
- Never invent testimonials, clients, project results, contact information, or social links.

## Workflow

- Inspect the existing project before making changes.
- Preserve unrelated user changes.
- Keep `MEMORY.md` updated when the user confirms an important project fact or decision.
- Verify the site at common mobile and desktop widths after meaningful UI changes.
- Run any available checks before handing work back.

## Definition of Done

The initial website is complete when it is responsive, accessible, visually consistent, uses Poppins, contains the agreed sections, has no obvious broken interactions, and clearly tells visitors who the freelancer is, what they offer, what they have created, and how to contact them.
