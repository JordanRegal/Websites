# Freelancer Portfolio Website

A clean, responsive one-page freelancer portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features

- Editorial-style responsive design
- Poppins typography
- Cream-beige, navy, and blue color palette
- Mobile navigation
- Scroll-reveal motion
- Accessible structure and reduced-motion support

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Customize

Replace the sample name, project content, social links, and `hello@example.com` in `index.html` with the final portfolio details.
